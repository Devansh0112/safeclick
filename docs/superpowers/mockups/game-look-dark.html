Max's Safe Trip: dark "hacker" looks

Max is a young cyber-guardian moving through the internet. Scam bots are the bad guys. Rough sketches, not final art: the real game would add animation (glow pulses, rain, scrolling code).

Part 1 · Which dark look?

Same level each time: Gate 1 cleared, Max jumping toward Gate 2 (active), Gate 3 locked, the exit portal is point B.

D · Neon City

Synthwave night city: glowing grid floor, pink and cyan neon, Max in a hoodie with a glowing visor. Highest "wow" factor, still clearly a game. Each world could be a different district (Link Alley, Password Tower…).

E · Terminal Grid

Black screen, green code rain, firewall gates shaped like { }, HUD styled like a command line. The most "real hacker" feel. Can look cold, and readability takes care with green-on-black.

F · Midnight Aurora

Dark navy with aurora light and frosted-glass gates. The "aesthetic" lo-fi mood: dark and moody but calm. Less hacker, more stylish. Easiest to keep readable.

Part 2 · Same gate flow, in look D (Neon City)

Habit: read the web address, every letter counts. Villain is a glitchy scam bot instead of a cartoon fisherman.

1 · The gate

Three portals, three addresses. Max waits to the side so his position doesn't give away the answer.

2 · Caught

A glitchy scam bot traps Max in a data cage, with a red glitch effect. Edgy but not scary. Same one-line red flag and retry.

3 · Level clear

Neon stars, the rule shown like a command, and the grown-up challenge framed as "can you beat your parent?"
